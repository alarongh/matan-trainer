# Предел.

Спокойный тренажёр по математическому анализу: все задания №1–10 экзаменационного билета.

**[Открыть сайт](https://alarongh.github.io/matan-trainer/)**

Дополнительно доступна [линейная алгебра и аналитическая геометрия](https://alarongh.github.io/matan-trainer/?subject=linear), 1 семестр 2025-2026. Выбор предмета находится над разделами. Банки заданий и прогресс разделены; содержание матана сохранено. Покрытие линала и форматы ответов описаны в [LINEAR.md](LINEAR.md).

Введи только итоговый ответ. Верный ответ переводит к следующему заданию; автоматический переход можно отключить. После ошибки открываются нужные формулы. Дальнейшие преобразования и ответ раскрываются отдельными нажатиями.

[Викторина формул](https://alarongh.github.io/matan-trainer/?practice=formulas): 58 формул матана и 48 формул линала. Выбери номера билета и собирай правую часть из перемешанных фрагментов. Волны идут без конца, ошибки раскрывают пошаговый разбор. Черновик, текущая волна и история формул сохраняются отдельно от заданий. Подробности в [QUIZ.md](QUIZ.md).

В 12 карточках отмечены особенности исходной записи: пропущенные аргументы, логарифм отрицательного числа в заданной точке, точка вне неявной кривой, неверный конец дуги, неоднозначный ориентированный угол и два явно оговорённых прочтения условия. В неполных условиях проверяется умение распознать проблему, а не выдуманный численный результат. Полный перечень есть в «Исходных материалах».

Устные темы представлены авторскими вопросами с выбором утверждений и пояснениями. Это самопроверка ключевых фактов, а не автоматическая проверка полного устного доказательства.

## История

Попытки, раскрытые этапы, текущая карточка, черновик ответа, фильтры и тема сохраняются в localStorage. Данные остаются в том же браузере на том же устройстве и адресе сайта. Удаление данных браузера удаляет историю. Для переноса есть «Скачать историю» и «Загрузить историю» в настройках; загрузка заменяет текущую историю. Учётная запись и сервер не нужны.

Задания с раскрытым разбором отмечаются «С помощью» и попадают в «Повторить». Разбор можно закрыть на любом этапе кнопкой «Закрыть разбор и очистить ответ»: поле ответа и подсказки очищаются вместе. При возвращении к решённому заданию ответ и разбор также скрыты, а история попыток и отметка результата сохраняются. Незаконченные черновики остаются. Памятка с общими формулами не меняет статус карточки.

Четыре темы: Шалфей, Тёплая бумага, Лаванда и Тихий вечер. Шрифты и математическая вёрстка загружаются с самого сайта. Интерфейс адаптируется к ширине и масштабированию; длинные формулы можно прокручивать внутри карточки.

Под полем ответа есть сворачиваемая математическая клавиатура: цифры, дробь, корень, степень, eˣ, π, ∞, скобки и дополнительные функции. Кнопки вставляют запись в позицию курсора; есть стрелки, удаление выделения и проверка. Корень и экспонента оборачивают выделенный фрагмент, а в пустом шаблоне курсор сразу оказывается внутри скобок. Обычная клавиатура продолжает работать.

## Формат ответов

Поддерживаются `2/3`, `0,5`, `sqrt(2)`, `3sqrt(3)`, `e^-3`, `exp(-3)`, `e^(-3*pi/4)`, `∞`, `-∞`, простые дроби и корни в LaTeX. Приближённые конечные ответы проверяются с относительной точностью 10⁻⁶; для нуля абсолютная точность 10⁻¹⁰. Лучше вводить точное выражение. Крошечная экспонента не считается нулём.

Несколько чисел: `-2;5`. Координаты: `(2;4)`, несколько точек: `(2;1/2) | (-2;-1/2)`. Прямые: `x=2; y=3x+1`. Порядок элементов не важен. Десятичную запятую можно использовать внутри координат, координаты разделяет `;`. Углы вводятся в радианах. Для отсутствующего предела, производной или точек используется «нет» в соответствующих карточках. В теории отмечаются все нужные утверждения; в последовательностях внимательно читай, требуется выбрать верные или НЕВЕРНЫЕ.

В задачах с параметром используются явно перечисленные переменные (`a`, `l`, `t`, `k`). Эквивалентность выражений проверяется численно в нескольких фиксированных точках, это не символьное доказательство. Прямые проверяются по коэффициентам и линейности. В нескольких полях ответы проверяются отдельно; при ошибке указывается поле, затем раскрывается первый шаг. Клавиатура вставляет запись в выбранное поле, оно выделено цветом.

Это проверка конечного ответа. По одному ответу нельзя определить, на какой строке собственного решения допущена ошибка; сайт показывает последовательный разбор задачи.

## Локальный запуск

Требуется Node.js 22 или новее.

```sh
npm ci
npm test
npm run build
npm run dev
```

Открыть `http://127.0.0.1:4173/`. Сборка находится в `dist/`; пути работают и в подпапке GitHub Pages. Публикация настроена через `.github/workflows/pages.yml` после отправки в `main`.

`data/tasks.json` содержит условия, ответы, этапы и ссылки на источники. `data/coverage.json` фиксирует покрытие и особенности исходников. `data/verification.json` содержит отдельные символьные проверки пределов, производных, касательных, асимптот и экстремумов. Полный банк воспроизводится с Python и SymPy через `python tools/build_all.py`; `build_bank.py` — только исходный набор №1–3. Для публикации Python не требуется: проверенный JSON уже в репозитории.

Ключ истории `matan-trainer:v1` и идентификаторы прежних 96 карточек сохранены. Сборка добавляет версию к ресурсам, чтобы обновления загружались без удаления истории браузера.

Браузерные сценарии: установить Playwright, затем запустить `npm run test:browser`, указав `PLAYWRIGHT_PATH` и при необходимости `BROWSER_CHANNEL`. По умолчанию используется установленный Edge. `TEST_URL` позволяет проверить опубликованный сайт. Результаты и снимки сохраняются локально в `test-results/`.

Проверки и границы проверки описаны в [QA.md](QA.md).
