# Проверка

## Дополнение из учебного пособия

Пособие дополнено до всех 837 практических упражнений из 26 разделов: 1017 карточек, всего в матане 1443. Проверены охват вариантов и подпунктов, принятие автоматически проверяемых эталонов и отклонение контрольных ошибок, строгая вёрстка KaTeX, дроби и десятичные формы. У 150 письменных карточек автоматическая проверка отключена; сохранение допускается после сверки всех этапов и контрольного списка. Независимые эталоны включают оба задания с пересдач, коэффициенты аргументов синуса/косинуса, производные, геометрические задачи, пороги N, многочлен Тейлора и гессиан.

Прежние 426 карточек и прежние записи математических проверок сохраняют прежние хеши; файлы линала не изменены. Подробности математической проверки и границы переноса описаны в [TEXTBOOK.md](TEXTBOOK.md).

После расширения: 27 автоматических тестов проходят; браузерные проверки пособия, письменной самопроверки и переходов проходят. Проверены 26 разделов, восстановление заметок и фильтра, отсутствие автоматической оценки письменной работы, контрольный список, сохранение как работы с разбором, очистка повторной попытки, SVG-график с масштабом, 320 px и 200%. Вёрстка телефона и компьютера просмотрена по снимкам.

Браузерный сценарий дополнения проверяет фильтр источника, ошибку и поэтапный разбор, верный ответ и следующий номер, очистку ответа при повторении, историю после перезагрузки, многополевой ответ, 320/390/768 px, масштаб 200%, переключение предметов и доступность исходного PDF.

## Содержание

- Все 353 пронумерованных упражнения банка включены; нумерация и повторы проверяются автоматическим тестом. Условия сверялись по тексту и изображениям PDF, спорные места — по изображению.
- Каждый пример сохраняет номер и ссылку на исходную страницу.
- Промежуточные преобразования проверены вручную. Пределы отдельно проверены SymPy; для ограниченных тригонометрических слагаемых использованы оценки и числовая перепроверка.
- Математические проверки находятся в `data/verification.json`: пределы, производные, касательные, частные производные, рациональные асимптоты и температуры на отрезках. Для степенных пределов формы 1^∞ отдельно вычисляется предел `(A−1)B`. Не каждая текстовая теорема имеет независимую машинную проверку.
- Все условия и формулы каждого этапа проходят строгую проверку KaTeX. У всех 426 карточек эталонный ответ принимается, контрольный неверный ответ не принимается.

## Поведение сайта

Проверены в браузере Edge/Chromium:

- ответы для всех 426 карточек: числа, утверждения, несколько полей, координаты, множества, прямые и выражения с параметром;
- неверный ответ раскрывает только первый этап, следующие открываются по кнопке;
- самостоятельное решение и решение с помощью учитываются отдельно;
- новая попытка после полного разбора;
- повторное открытие страницы сохраняет попытки, выбранную карточку и тему; у незаконченных задач сохраняются этапы и черновик, у решённых ответ и разбор очищаются;
- скачивание истории и загрузка в чистый браузерный профиль;
- автоматический переход к следующей карточке;
- памятка и математическая вёрстка;
- ширины 320, 390, 768, 1024 и 1440 px, масштаб 200%;
- отсутствие ошибок JavaScript и неудачных HTTP-запросов.

Отдельные проверки новых форматов: порядок точек/прямых не важен, дроби и десятичные координаты эквивалентны, нелинейное выражение в поле прямой отклоняется, неполный набор утверждений не засчитывается. Старый формат истории по-прежнему загружается, новые разделы №4–10 сохраняются.

Сценарий npm run test:retry проверяет повторные попытки в обоих предметах: старые сохранённые ответы решённых задач, обычное поле, несколько полей, галочки, возврат после автоматического перехода, перезагрузку и очистку на любом этапе разбора. История попыток сохраняется, незаконченные черновики не очищаются.

Дополнительно проверены клавиатура мышью и касаниями, ввод правильного ответа через дробь, корень и экспоненту, курсор внутри шаблона, замена выделения, удаление, ограничение длины, сворачивание и сохранение черновика. Условия используют полные обозначения arctan/arccot/arcsin; сокращения atan/acot/asin не выводятся. Запуск отдельного сценария: `npm run test:keyboard`.

Четыре цветовые темы имеют отдельные настройки. Анимации отключаются при системном предпочтении reduced motion. Для ответов применяется арифметический парсер без eval; код, доступ к свойствам и неопределённая арифметика отклоняются.

Автоматические проверки не гарантируют готовность к экзамену. Проверка интерфейса на физических iPhone/Android не проводилась; мобильные размеры проверены в браузере. История локальная: автоматической синхронизации между устройствами нет.
