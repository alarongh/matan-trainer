# Учебное пособие по математическому анализу

Источник: «Математический анализ (1 семестр). Учебное пособие», МИРЭА, Москва, 2019, 128 страниц. Оригинал доступен в sources/textbook.pdf; каждая новая карточка открывает страницу своего условия.

Перенесены упражнения, соответствующие нынешним №1–10 билета: **657 исходных упражнений, 747 карточек**. Девяносто упражнений на построение графиков дают по две карточки: точки перегиба и асимптоты. Это адаптация к №7–8 билета, а не автоматическая оценка полного рисунка графика. Остальные условия сохраняют все числовые данные, исходные номера и буквенные подпункты. Независимые повторения остаются отдельными карточками.

## Задания с пересдач

- Задача 7, №9, стр. 21: lim (6−5/cos²x)^(1/x²), ответ e^(-5).
- Задача 7, №13, стр. 22: lim ((1+2^x)/(1+3^x))^(1/sin x), ответ sqrt(2/3).

Оба есть и в общем списке, и в фильтре «Учебное пособие». Исходные номера видны в списке и ссылке на PDF. Буквы а, б, в представлены техническими суффиксами a, b, c.

## Особенности источника

Четыре условия требуют проверки корректности: 6/19в — отрицательное основание переменной вещественной степени при x→+∞; 11/17 — неположительное основание (ln sin3x)^x; 14/8 — вторая точка вне кривой; 15/19 — внешний логарифм отрицательного ln(2−x). В них проверяется выбор «условие требует уточнения», и проблема объясняется по шагам. Указанная преподавателем другая редакция условия была бы отдельной задачей.

В 6/5а, 6/8в и 19/3а двусторонний предел не существует; это не замена условия и не опечатка. Подход с обеих сторон разбирается отдельно. В 6/6в, 6/14в, 6/15в и 16/5 явно отмечена сторона естественной вещественной области. Напечатанная константа ln12 в 19/5б сохранена; предел этой печатной дроби равен 0.

Координаты перегибов приведены приближённо, с 12 значащими цифрами; для проверки нужно вводить не менее 8 знаков после запятой. Для бесконечных семейств в 22/11 и 22/16 используется целый параметр k.

## Воспроизведение и проверка

python tools/build_textbook.py идемпотентно добавляет этот источник к текущему банку; нужны SymPy 1.14 и mpmath 1.3. Полная сборка tools/build_all.py также подключает новый источник. Для публикации Python не нужен: подготовленный JSON хранится в репозитории.

npm test проверяет охват всех вариантов, математическую вёрстку, принятие эталонов и отклонение контрольных ошибок. Отдельные независимые значения закреплены в tests/textbook.test.mjs. Хеш прежних карточек и прежних записей проверки фиксирован в тесте: дополнение не переписывает их.

Пределы численно перепроверяются при 100 знаках точности и трёх расстояниях; для медленной логарифмической сходимости дополнительно используется символьный предел. Пределы степеней проверяются через логарифм. Производные перепроверяются численным дифференцированием; неявные и параметрические — соответствующими тождествами. Для смешанных производных проверяется равенство порядков. Точки перегиба отбираются по области и смене знака второй производной; практические модели проверяют критическую точку и вторую производную. Эти проверки подтверждают вычисления, но не являются формальным доказательством каждой геометрической модели или корректности исходного текста.

npm run test:textbook проверяет источник и ответы в браузере, этапы, очистку ответов, переходы, сохранение прежнего прогресса, ширину 320 px, масштаб 200%, переключение на линал и доступность PDF.
