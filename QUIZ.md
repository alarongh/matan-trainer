# Викторина формул

В каждом предмете доступен режим «Формулы». Он содержит 58 карточек матана и 48 карточек линала, распределённых по всем десяти номерам билета. Это авторские карточки для повторения правил, используемых в заданиях; сами банки заданий сохранены.

Можно выбрать несколько номеров одновременно. Сайт показывает левую часть формулы, условия применения и места для правой части. Нажми на место, затем на подходящий фрагмент. Фрагменты можно использовать повторно; лишние варианты содержат типичные ошибки. Равнозначные перестановки множителей и слагаемых принимаются там, где они предусмотрены карточкой.

После ошибки отмечаются места, которые нужно исправить, и открывается первый этап разбора. Следующие этапы показывают часть сборки, полную формулу и пояснение. Помощь можно запросить до проверки. Ответ после открытых подсказок учитывается отдельно от самостоятельного воспроизведения.

В одной волне встречается каждая выбранная формула. В следующих волнах формулы с ошибками получают дополнительное повторение, пока не появятся два самостоятельных верных ответа подряд. Автоматический переход к следующей формуле можно отключить. При уходе из викторины или скрытии вкладки ожидающий переход отменяется.

История, перемешанные фрагменты, черновик, номер волны и настройка перехода сохраняются в localStorage данного браузера. Ключи formula-quiz:matan:v1 и formula-quiz:linear:v1 разделены по предметам. Прогресс обычных заданий и общая тема оформления не меняются. Экспорт истории обычных заданий не включает викторину.

Проверки: npm test проверяет формулы в KaTeX, допустимые перестановки, генерацию волн, учёт подсказок и восстановление состояния. npm run test:quiz проверяет все 106 карточек в браузере, четыре этапа, смену предметов, сохранность прогресса заданий, темы, сенсорные нажатия, ширину 320 px и масштаб 200%. Для короткой проверки публикации используется переменная TEST_SMOKE=1, для адреса сайта — TEST_URL.
