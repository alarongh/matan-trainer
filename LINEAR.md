# Линейная алгебра и аналитическая геометрия

1 семестр 2025-2026. Дополнительный предмет в том же приложении.

[Открыть линал](https://alarongh.github.io/matan-trainer/?subject=linear). Предмет также выбирается над списком разделов. Без параметра URL открывается прежний матан.

## Материалы и покрытие

121 карточка: 91 из предоставленных материалов и 30 авторских вопросов для проверки понимания теории.

- Все 63 примера 3.1-3.63 из пособия «Это надо знать к экзамену 2026».
- Все 56 вариантов номеров 1-10 из образца билета. 48 совпадают с примерами пособия и имеют дополнительные ссылки; 8 отличаются и сохранены отдельно.
- Два полных тренировочных билета из пособия, по 10 номеров.
- Все 30 тем списка «Вопросы на сессию»: исходная тема, авторская проверка и краткий план устного ответа. Один тестовый вопрос не заменяет раскрытие всех подпунктов темы.

Исходные PDF доступны в разделе материалов, карточки ссылаются на соответствующие страницы. `data/linear-coverage.json` содержит карту каждого варианта образца. Пропуски мнимой единицы, опечатки в ответах и отличающиеся условия отмечены явно. Условие с напечатанным y³ сохраняется как задача на проверку корректности, а не молча заменяется на y².

## Ответы

- Матрица: `1 2; 3 4`. Элементы через пробел, строки через `;`. Дробь `1/2`, точка `0.5` и запятая `0,5` равнозначны. Допускается JSON `[[1,2],[3,4]]`; в JSON числа записываются через точку, либо выражения заключаются в кавычки.
- Комплексное число: `2-3i`, `sqrt(2)*(1+i)` или `1/(1+i)`. Все корни через `;`, порядок не важен.
- Координаты: `(1;2;3)`. Порядок координат важен.
- Уравнения плоскостей и кривых принимаются в равносильной форме, с ненулевым общим множителем.
- Прямая: `x=-1+3t; y=2-2t; z=3-t` или `(x+1)/3=(y-2)/(-2)=(z-3)/(-1)`.
- Общее решение СЛАУ: `(11-14t;6-4t;t)`. Принимается другая линейная параметризация той же прямой решений. Для частного решения проверяются все исходные уравнения.
- Сопоставление: отдельное числовое поле для каждого пункта, `1=А`, `2=Б` и т.д.; варианты перечислены в условии.

Комплексный парсер выполняет только арифметику, без `eval`. Уравнения проверяются по коэффициентам многочленов первой и второй степени; дополнительно проверяется их степень в нескольких точках. Произвольное символьное доказательство эквивалентности не выполняется. Чертежи являются схемами с одинаковым масштабом по осям и раскрываются в последнем шаге. Геометрический рисунок пользователя сайт не проверяет.

## Изоляция матана

Цветовая тема общая для обоих предметов и хранится отдельно в `trainer:theme:v1`. При первом запуске после обновления используется прежняя тема открытого предмета. Переключение предмета, загрузка или сброс истории не меняют общую тему. Изменения оформления синхронизируются и между открытыми вкладками того же браузера.

`data/tasks.json`, `data/coverage.json`, `data/verification.json`, исходные материалы матана, его парсер и формат состояния не изменены. Математический анализ продолжает использовать `matan-trainer:v1`, линал использует `linear-trainer:v1`. Переключение перезагружает страницу с другим предметом и не очищает другую историю. Экспорт содержит предмет; загрузка истории другого предмета отклоняется. Старые файлы истории матана по-прежнему принимаются в матане.

## Воспроизведение и проверка

Для пересборки линала нужен Python с SymPy и pypdf и исходные PDF в указанной в `tools/build_linear.py` папке: `python tools/build_linear.py`. Этот скрипт не изменяет банк матана. Для обычной сборки Python не нужен; JSON сохранён в репозитории.

`npm test` проверяет все 121 эталонный ответ, ошибочные ответы, формулы KaTeX, покрытие источников, эквивалентные записи и неизменность банка матана. `data/linear-verification.json` содержит 104 точные проверки вычислений через SymPy. `npm run test:linear` проверяет все карточки и этапы в браузере, переключение предметов, сохранение, импорт/экспорт/сброс, графики, клавиатуру, темы и узкие экраны. `TEST_URL` позволяет запустить сценарий на опубликованном сайте; `TEST_SMOKE=1` сокращает проход до 20 карточек разных типов, сохраняя проверки хранения, импорта, экспорта и интерфейса.
